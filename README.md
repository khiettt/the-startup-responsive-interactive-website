### Detail element 
Het details element in HTML zorgt ervoor dat je informatie kunt verbergen en pas laat zien wanneer iemand erop klikt. 

_HTML:_

https://github.com/khiettt/the-startup-responsive-interactive-website/blob/e1c4a0a57332fbe01016bc8f881b7e25040f8fc3/index.html#L48-L61

_CSS:_

Om de detail element mooi te stijlen heb ik van de shadow-root een class gepakt. De "block-size" zorgt er voor dat het wel of niet zichtbaar is.

https://github.com/khiettt/the-startup-responsive-interactive-website/blob/e1c4a0a57332fbe01016bc8f881b7e25040f8fc3/werktijden.css#L148-L182

De property en value die je hier beneden ziet zorgt ervoor dat CSS-animaties soepel verloopt. 

https://github.com/khiettt/the-startup-responsive-interactive-website/blob/e1c4a0a57332fbe01016bc8f881b7e25040f8fc3/werktijden.css#L11-L13

Om de shadow-root te kunnen zien moet je in je devtools opzoek naar "elements" en de user agent aanklikken.
